# 星轨 Orbit

面向手机的星际伙伴看盘应用。用分组伙伴管理自选标的，以可滑动的卡牌查看价格、迷你 K 线、方向概率、上行与下行参考区间，并提供相关新闻与历史回测。

支持 OKX USDT 永续合约及沪、深、北交易所 A 股。账户、自选、已获取行情和品牌资料保存在本机服务的 SQLite 数据库中。

## 快速启动

运行环境：Python 3.11 或更新版本、系统 `curl`。普通页面运行使用 Python 标准库，不需要安装第三方 Python 包；验证脚本和回测引擎还需要 Node.js 18 或更新版本、Bash 和 Git。

```bash
python3 server.py
```

打开 <http://127.0.0.1:8000/>。首次运行可在终端输入可选的 Finnhub API Key，也可直接回车；没有 Key 仍可使用公开行情、搜索和 A 股资料。

指定端口：

```bash
MARKET_PORT=8001 python3 server.py
```

服务监听 `127.0.0.1`。手机访问需要将现有本地服务接入已配置的访问入口；临时隧道链接属于运行环境，不写死在项目文档中。

## 手机使用方式

- 首页的星际伙伴对应自选分组。点伙伴进入卡组；管理页可改名字、选形象、搜索标的，并通过卡兜调整顺序和移除标的。
- 卡牌左右滑动切换标的。Logo 打开简短资料，迷你 K 线可展开完整图表，返回后保留当前卡片位置。
- 已持有的搜索结果标记“已在自选中”；本次刚添加的标的显示“点一下取消”。状态固定在标的右侧预留列，不弹出跳动提示，状态切换不增加行高。
- 新闻和分组添加共用标的目录匹配，支持代码、中文名称、别名、交易对名称及近似拼写。
- 新闻列表采用同一朝向、等高的古朴剪报纸页，保留原标题、来源、时间和已有摘要，点击整张纸页打开原新闻链接。使用指南整理为连续手册，保留原说明和单一返回入口。
- 伙伴图鉴展示个人形象和世界观资料；玻璃展舱使用一体素材，内部角色支持手动切换视角，伙伴名字旁不显示链接箭头。
- 主入口使用移动端界面；宽屏窗口保留有界的手机画布。手机旋转和键盘收起后重新计算画布，背景单独扩展到安全区和浏览器工具栏变化区域。

## 启动加载与音效

加载页自动进入，没有音效确认按钮。进度条按已完成的准备阶段平滑推进，快速连接时也保留短暂的加载过渡。

准备阶段包括页面样式、账户恢复、已登录用户的热门卡组与标的目录、字体、首屏图片解码、音效资源和最终布局。完成的项目显示勾选文字；关键资源失败时保留加载页，可点击“重新加载”。进度代表启动阶段完成情况，不是下载字节百分比。

滑动、卡兜和伙伴操作音效在启动阶段提前生成并复用。部分手机浏览器会暂停音频，首次正常点击或触摸时会尝试启用；恢复前台后也会尝试恢复音频。音效资源准备完成与浏览器允许播放是不同状态，音频暂停不会阻止自动进入。

## 市场与标的身份

| 市场 | 标的身份示例 | 价格币种 | 行情来源 |
| --- | --- | --- | --- |
| OKX USDT 永续 | `swap:BTC`、`swap:AAPL` | USDT，界面使用 `$` | OKX 公开合约行情 |
| 沪深北 A 股 | `ashare:SH600362`、`ashare:SZ002384` | 人民币，界面使用 `¥` | 东方财富 A 股目录和公开行情 |

股票关联合约与证券交易所股票属于不同标的。即使公司名称相同，也按市场和代码独立搜索、添加、缓存和展示。A 股显示“A股”，不会标为“永续”；股票关联合约的价格也不会转换成人民币股票报价。

标的目录是可搜索的清单，不代表所有公司资料与图片已经下载。搜索和添加会登记需要获取的标的，刚选中的标的优先准备资料。后台工作限制并发并合并重复请求，不在手机启动时下载全部标的的历史行情。

## Logo、简介和缓存

- 成功获取的 Logo 图片、来源、官网及简短简介会写入行情数据库。后续搜索直接携带已存图标地址，当前页面获取成功后自动更新。
- A 股公司资料按证券代码和交易所核对，官网图标必须来自核对过的公司网站。支持 PNG、JPEG、WebP、ICO 及经过安全检查的静态 SVG，图片上限为 512 KiB。
- 对已核对的重点公司提供本地品牌素材和一两句主营业务简介。资料框尺寸一致，内容按完整句子简化，卡面不显示历史样本数或等待确认说明。
- 未能核实或官网拒绝请求时，保留代码标识和已存有效资料。新标的首次访问仍可能需要等待上游返回；失败不会删除已有图标。
- Logo 与简介使用独立于慢行情请求的准备队列。页面读请求会合并并发调用；“正在获取”等响应不会作为成功结果长期缓存。
- 图片来源记录位于 `assets/icons/brand/`、`assets/icons/okx/` 及相关 `*-SOURCE.md` 文件。

公开行情会优先显示有效缓存，再向上游同步。无法更新时接口可返回 `stale: true`；旧数据仍是历史缓存，不表示实时行情已更新。手机公共数据缓存跨页面关闭保留，包含标的目录、最多 500 条资料、Logo 地址与最近 K 线快照；独立命名空间上限约 4 MiB，超限淘汰旧公共条目。素材通过 HTTP 缓存与内容校验复用。服务端 SQLite 缓存跨重启保留，实时行情仍联网更新。

回测页面沿用主应用的星海背景和导航样式，顶部保留一个箭头返回入口。从主屏进入时优先返回原页面记录，以保留卡牌位置；直接打开时返回应用首页。

### 本地保存与后续 APK

项目包含 `android/` 中的 Android WebView 客户端及构建脚本，行情、新闻和标的资料由服务接口提供。桌面及普通 Android 浏览器进入下载页，iOS 浏览器和 APK 客户端进入应用。签名密钥、APK 构建产物、用户账户数据库和整份行情资料库不纳入源码仓库。

自选属于用户设置，不按行情缓存的有效期删除。当前实现将修改即时写入手机的账户专属本地待同步记录，并同步到服务端账户数据库；账户切换使用不同存储空间。自选标的的资料与图标受缓存保留保护；非自选、长期不访问的缓存可以淘汰。清除浏览器数据、卸载应用或系统回收网站存储仍可能删除手机副本，服务端已同步的自选可以在重新登录后恢复。

价格和 K 线属于可更新数据：先展示可用缓存，再联网刷新，失败时标记旧数据。客户端缓存、服务端持久资料库与用户自选分别管理，资料检查周期不代表实时行情的更新周期。后续做 APK 时需验证固定应用来源、Cookie/登录、存储迁移和系统存储回收行为，再选择原生持久存储；目前保留现有逻辑。

## 热门、图表与分析

热门榜由公开 OKX 行情计算，分别选择加密资产类和股票相关类各 10 个标的。服务每四小时重新计算，北京时间跨日也会更新；上游失败时保留上一份有效榜单。页面仅显示“热门”，不额外展示更新时间。

图表支持按市场允许的周期切换、历史拖动与双指缩放。卡面使用“上行、观望、下行”统一标签；概率和参考区间使用已完成 K 线计算，手机与完整图表共用分析逻辑。

概率表示同类历史结构的频率，参考区间和盈亏比属于基于历史行情的估计，不包含所有手续费、滑点及资金费率。更完整的策略和回测说明见 [回测文档](backtest/README.md)。

## 配置与数据位置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `MARKET_PORT` | `8000` | 本地服务端口 |
| `MARKET_ACCOUNT_DB` | `.market_accounts.sqlite3` | 账户、自选与分组数据库 |
| `MARKET_DATA_DB` | `.market_data.sqlite3` | 公开行情、资料、Logo 和响应缓存 |
| `MARKET_PUBLIC_HOST` | 空 | 允许访问服务的指定主机名 |
| `FINNHUB_API_KEY` | 空 | 可选新闻及公司资料数据源 |

账户密码使用 scrypt 哈希，登录会话使用 HttpOnly Cookie。账户数据库、环境文件、令牌、运行日志和个人缓存不属于 GitHub 发布内容。

迁移应用时保留两个 SQLite 数据库及 `assets/icons/`。数据库可能有 WAL 日志，备份请使用 SQLite backup API，或停止服务后复制数据库及对应日志；不要在运行期间只复制主文件。更详细的说明见 [数据库维护](docs/database-maintenance.md) 和 [数据校验](docs/data-integrity.md)。

## 同步到 GitHub

本项目使用 [Gh811/orbit-market-lab](https://github.com/Gh811/orbit-market-lab) 的 `main` 分支。配置 Git 推送授权后使用：

```bash
bash scripts/publish-update.sh "说明本次修复和改动"
```

脚本先完成移动端检查，再暂存应用源码、README、文档、测试和必要公开素材，创建提交，最后推送到 `origin` 的当前分支。不强制推送，不替换远程历史。

`.gitignore` 排除账户和行情数据库、环境文件、日志、生成预览及备份目录。每次更新同步 README 中受影响的功能和运行说明；发布脚本不会自动改写产品文档。首次关联远程仓库的地址和公开范围由项目所有者指定。

## 素材来源

品牌标识及插画来源以素材目录中的说明为准。报纸图标由 [Twemoji](https://github.com/twitter/twemoji/blob/master/assets/svg/1f4f0.svg) 修改，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。江西铜业图标直接保存官网原始图片，详情见 [来源记录](assets/icons/brand/SH600362-SOURCE.md)。

移动端显示：指南在一屏内展示六项操作；加载说明区域预留固定高度；所有新闻入口使用独立纸页；卡牌慢拖需要约三分之一宽度，保留阻尼；快速同向甩动可在较短距离切换，仍有最小距离保护。报价保存到 SQLite，上游暂不可用时已有报价明确显示为缓存价格，并继续重连。

指南关闭后整个页面立即隐藏，主题样式仅在打开状态下启用，避免返回时残留标题行。

新闻和指南按整个功能返回主界面。新闻搜索、选择标的和列表切换都属于新闻内部操作，不增加返回层级；点击返回直接退出新闻功能。卡牌切换和表单修改只更新本页状态。

完整返回层级见 [移动端界面目录](docs/界面目录.md)，代码使用 `assets/mobile-pages.js` 的 `pageDirectory` 统一定义主功能、子功能与操作弹层。

手机星海背景使用一个独立的原生固定层，四边向屏幕外延伸。背景不使用卡牌、对话框或手机内容画布的高度变量，浏览器工具栏与键盘改变可视高度时仍覆盖屏幕。主界面、卡牌与分组管理共用同一张背景，进入功能不切换根背景底色。

卡牌侧边厚度随左右转动角度镜像投影，静止时居中；左右滑动都能看见对应侧边，回弹时厚度边框同步收回。

所有 A 股公司资料统一按证券代码和交易所核对，优先读取主营业务字段，再用公司概况来源回退。成功资料与官网信息写入数据库；缺失资料继续重试，失败不覆盖已核实简介。新闻、登录和账户接口不进入公共资料缓存；这不等于整站无需联网或浏览器永久保留数据。

本地缓存按浏览器和访问域名隔离。更换临时访问域名或清理浏览器数据会重新建立缓存；正式运行应使用稳定域名，以持续复用下载内容。

## 固定发布版本，避免新旧界面混用

JS、CSS 的引用由服务端按实际文件内容生成版本号，不再依赖手动修改日期标签。只有版本号与文件内容匹配的资源才长期缓存；旧版本标签和未标记的资源都会重新校验。HTML、账户和实时接口使用 `no-store`。

`python3 scripts/build-release.py` 会把当前源码、公开素材和必要公开目录复制到 `.releases/` 下独立的发布快照，并生成 `release.json`。账户、行情数据库、日志、环境文件、备份和临时预览不会进入快照。正式服务应从固定快照启动，数据库通过 `MARKET_ACCOUNT_DB`、`MARKET_DATA_DB` 指定到原有绝对路径。后续工作区编辑不会改变正在运行的代码；切换版本时再重启服务。`/api/status` 的 `release` 字段可核对实际运行的发布版本和 Git 提交。

从主界面的回测图标进入时，回测在同源子页面中打开；返回只关闭子页面并释放图表，不重新加载主界面，不退出全屏。顶部固定保留安全区与顶栏，正文在其下方滚动，背景覆盖完整屏幕。回测参数只读，用户仅选择策略。

旧备份和已停用的探测车模型实验已做本机可恢复归档，位于忽略上传的 `.local-archive/`。伙伴原图、视角图、当前素材、回测验证记录和运行数据库保留。

标的资料库预采集使用 `python3 scripts/prefill-assets.py`。它先保存完整公开目录，以最多 2 个工作线程分批获取公司/币种资料与匹配图标；优先处理重点标的和已自选项，正常资料 30 天内复用，失败项隔日再试。任务进度保存在不上传的 `.asset_prefill_status.json`，再次运行可续采，资料与图标存入原有行情 SQLite 数据库；此任务不批量请求 K 线，也不依赖用户逐个打开标的。

手机端完整资料按标的单独持久保存，图标原始图片通过 Cache Storage 保存；页面再次打开优先使用已有资料及图片。当前自选项受保护，未自选项闲置 30 天后逐步清理；清理只针对手机缓存，服务器自己的资料库持续保留。完整资料每 30 天允许检查更新，不再每小时重新请求；未完整获取的条目继续有限重试。缓存被系统禁用或配额不足时，页面仍可正常读取服务端数据。行情和 K 线维持独立的实时/短时更新与历史缓存。所有资料页采用统一基础栏位，不追加 A 股行业、公司全称等单独栏目。

资料库迁移工具：`python3 scripts/transfer-asset-library.py export` 把当前采集结果导出为 `.local-data/asset-library-日期时间.sqlite3`。导出使用一致的数据库读取快照，包含目录、公开简介、官网、图标原始字节及资料响应，不包含用户账户和 K 线历史。采集进行中也可以导出，但仅代表当时已经保存的资料。把文件复制到服务器后运行 `python3 scripts/transfer-asset-library.py import --snapshot /服务器路径/asset-library.sqlite3 --database /服务器路径/.market_data.sqlite3`；导入按时间合并，旧资料不会覆盖服务器已有的新资料。服务通过 `MARKET_DATA_DB` 指向该数据库，即可读取这些资料。独立快照和运行数据库都不上传 GitHub。

`python3 scripts/audit-asset-library.py` 生成按身份匹配、简介、官网和本地图标分别核对的报告，不把占位文字算作完整资料。`python3 scripts/start-local-release.py --replace-pid 当前本应用服务PID --public-host 已确认的访问域名` 会创建固定代码快照并切换本地服务；数据库保留原路径，公开目录放在 `.local-data/catalogs/` 单独更新，运行状态和日志放在 `.local-data/runtime/`。状态接口的 `gitDirty` 表明是否含未提交的本地改动，`sourceHash` 对应该固定快照。

资料补采可使用 `--batch-profiles --retry-incomplete --metadata-only` 先补简介和官网，再使用 `--logos-only --include-missing-logos` 检查缺图标项。默认并发为 2；独立资料任务最多 6、独立图标任务最多 12。不把单个来源故障升级成整批中断，失败类型保存在公开资料库中。资料阶段进度使用 `.asset_metadata_status.json`，图标阶段使用 `.asset_prefill_status.json`，完整性以审核报告为准。
