# 移动端界面目录与返回规则

主界面是功能入口。主功能的返回直接回主界面；真正跳转到子功能界面时，返回到目录里明确指定的父功能。功能内部操作不建立页面记录。

| 界面 | 上级界面 | 说明 |
| --- | --- | --- |
| 卡牌 | 主界面 | 切换标的仍在同一个卡牌功能中 |
| K 线 | 卡牌 | 独立子功能，周期切换只是内部操作 |
| 分组管理 | 主界面 | 修改名字、选形象、整理卡兜均是内部操作 |
| 添加标的 | 分组管理 | 独立搜索界面；输入和点击候选不增加层级 |
| 标的资料 | 打开资料的功能界面 | 返回到对应卡牌、K 线或分组管理 |
| 新闻 | 主界面 | 搜索、选择标的、列表切换都在新闻功能内，返回直接回主界面 |
| 指南 | 主界面 | 一屏显示，返回直接回主界面 |
| 图鉴 | 主界面 | 翻阅图鉴不增加层级 |
| 伙伴档案 | 图鉴 | 选择不同伙伴、拖动展示不增加层级 |
| 个人 | 主界面 | 登录状态、表单输入属于内部状态，账户权限规则保持不变 |
| 修改密码 | 个人 | 真正子功能页面 |
| 功能菜单 | 主界面 | 功能导航入口 |
| 菜单中的显示设置、搜索添加、相关新闻、图表解读 | 功能菜单 | 独立子功能；各自内部操作不增加层级 |
| 管理分组、提醒记录 | 主界面 | 独立主功能 |

周期选择、自选操作和删除确认等弹层是操作界面：关闭时收起弹层，保留所属功能，不新增页面返回记录。

代码目录在 `assets/mobile-pages.js` 的 `pageDirectory` 中。新增完整界面时必须明确登记名称与上级；未登记的弹层按内部操作处理。选中的卡牌、搜索条件及表单草稿属于页面状态，不参与判断是否进入新界面。
