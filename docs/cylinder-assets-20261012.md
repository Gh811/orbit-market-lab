# 伙伴旋转与圆柱培养缸素材

使用内置 image_gen 工具生成，非 CLI。原始 PNG 保存在 assets/pets/turntables。运行时使用 assets/icons/crypto/turntablea.png、turntableb.png、cryotank.png。网页仅在进入伙伴资料后加载相应旋转图，每张图共享给四个伙伴；失败可点状态重试。

八个角度分别为 0、45、90、135、180、225、270、315 度，循环展示。角色背面是补绘图案，并非把正面镜像。实现为多角度图片展示，不是任意视角的实时三维网格模型。
