# 代码发布与安卓客户端

GitHub 主仓库为 Gh811/orbit-market-lab，发布分支为 main。只有已经可以部署的改动才合入 main；开发可以使用 codex/ 前缀分支。GitHub Actions 执行检查；服务器自己的定时任务也独立执行检查，不依赖 GitHub 检查状态可读性。

服务器每五分钟检查 main。更新程序以独立 orbit-build 用户拉取代码并执行测试，构建内容寻址的代码快照。检查通过后才切换 /opt/orbit/current 并重启应用；启动检查失败恢复旧链接。发布仅更新代码，绝不复制本地账户或覆盖 /opt/orbit/state。后台回测正在执行时，服务重启可能中断该任务，完成结果应重新运行。生产更新日志使用 journalctl -u orbit-update 查看；暂停更新为 systemctl stop orbit-update.timer。

网页 HTML 禁止缓存，脚本样式按内容哈希版本化。页面携带版本号并随 API 请求发送；移动端每十五秒及回到前台时检查版本。服务器切换版本时仅清除旧登录会话，保留所有用户记录；旧页面被禁止登录和写入，必须点击不可跳过的更新入口，加载新页面后重新登录。相同版本重启不会重复退出。个人页底部显示页面实际版本号。此前不含强制更新脚本的旧页面，先由接口拒绝并退回登录，需刷新一次以启用新机制。

安卓工程位于 android。它是需要联网的轻量 WebView 客户端，包名 com.orbit.market，最低 Android 8.0，连接 https://myok888.top/。网页功能随服务器更新，原生功能更新需要提高 versionCode 并使用相同签名重新发布 APK。私钥、签名密码和 APK 不进入 GitHub。

Linux 构建需 Java 17、Android SDK platforms;android-35、build-tools;35.0.0，运行 android/build.sh，并设置 ANDROID_HOME、ORBIT_KEYSTORE、ORBIT_KEY_PASSWORD_FILE。发布包为 android/build/orbit.apk。生产下载文件放在 /opt/orbit/state/downloads/orbit.apk，通过 MARKET_APK_FILE 配置，代码更新不覆盖它。下载入口为 /download，校验值为 /downloads/orbit.apk.sha256。需要自行备份签名材料；丢失签名私钥将影响后续覆盖安装。

资产页支持从现有目录选择 A 股或 OKX 永续参考标的，按当前持仓数量和买入均价计算参考估值、浮动盈亏与收益率，按买入日期后的已完成日线显示历史变化。永续参考估值不是杠杆合约结算盈亏。不同币种分别统计，不隐式换汇。缺少报价不按零值计算，缺失日线不补造；默认历史范围是提供方当前可用的近期日线，并非保证从买入起所有历史。当前数量与均价不重建历次交易，不含手续费、税费、资金费、拆股和分红。

访问入口按设备区分：电脑访问主域名只展示下载页，不加载移动应用脚本、宠物和账户数据；手机、iPad 与安卓平板继续进入移动应用；安卓显示下载按钮，iPhone 与 iPad 不显示。iPad 桌面模式会先经过轻量触控识别入口，避免将 Mac 风格 UA 直接当成电脑。显式 /download 地址仍可用于下载安卓包；苹果设备访问该页面时隐藏 APK 按钮并提示暂无 iOS 安装包。

滑动性能：视口滚动事件按动画帧合并；屏幕尺寸不变时不再改写整套媒体查询或重复设置根节点 CSS 变量；导航观察器忽略宠物动画、触摸反馈等与页面切换无关的 class 变化，保留真实页面切换和窗口适配。
