# 策略回测页面

在项目根目录运行 `python3 backtest/server.py`，打开 http://127.0.0.1:8130/ 。可用 BACKTEST_PORT 改端口、MARKET_DATA_DB 指定数据库。需要 Python 3 和 Node.js，无额外包。

独立运行，不导入主服务、不修改行情数据库、不自动补下载历史数据。标的候选来自数据库已保存的 K 线；没有数据或预热不足时明确报错。页面提供周期、风险预算、手续费、滑点、最长持仓、历史窗口、信号拦截原因、资金曲线与 CSV 导出。默认使用最近 12,000 条缓存记录，保留确认完成的 K 线。

运行检查：`node tests/backtest.test.cjs`。

首次 BTC / ETH 4h 实际结果在 artifacts/backtest-20261012/，包含完整 JSON 和 report.md。默认参数下两者均无交易，报告没有调整策略阈值。不能以零回撤推断策略安全。

复用 assets/strategy.js，主服务修改策略后本页面也会使用新策略；每次结果包含策略文件 SHA256。单周期分析，不模拟多周期联合确认。为提高性能默认截取 1,200 根历史用于每次分析，和其他页面使用不同数据长度时可能产生不同历史频率，窗口必须作为回测参数记录。

没有资金费率、盘口成交、部分成交或杠杆强平模拟；收盘盯市最大回撤不包含完整盘中风险。缓存缺口采用缺口前平仓、之后重新预热的规则，不能替代连续完整数据的回测。利润因子在没有亏损交易时显示空值。买入持有是测试起点收盘至结束收盘的毛价格收益，与下一根开盘成交的策略有时点和费用口径差异。

## 模拟交易与年化升级

页面默认选择 trendPullback v1 独立研究策略，可切换 cardStrict 原卡牌策略。规则详见 strategies.cjs 和页面执行说明；主应用策略保持原样。新增复合年化 CAGR、逐年盯市收益、逐年平仓数。实际四组结果及完整成交明细在 artifacts/backtest-annualized-20261012/report.md 与同目录 JSON。

验证：node tests/backtest-annualized.test.cjs；node tests/backtest.test.cjs。

回测页沿用星轨的星海背景、蓝灰色面板与金色主按钮。顶部只保留一个 44 × 44px 箭头返回入口；从应用首页进入时优先恢复原页面记录，直接打开时使用首页链接。策略表单和结果区域使用一致的圆角、边框、字号和间距，手机上自动按窄屏排列，计算规则、任务接口与导出内容保持原样。
